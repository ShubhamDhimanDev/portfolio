### A bit about me

I taught myself to code in the middle of a mechanical engineering degree, chasing the same feeling I got the day that first PC showed up — that you could type something precise and a machine would just *do it*. That feeling never wore off. These days it shows up as a slightly unhealthy love for systems that have to stay correct under pressure: real-time state, concurrent writes, infrastructure that isn't allowed to fall over.

I've spent the last 4.5+ years as a full-stack developer, mostly living at the intersection of **Laravel/PHP** on the backend and **React/Next.js** on the front — architecting things end-to-end, from schema design down to the last pixel. Most of the bugs I've chased in production turned out to be architecture problems wearing a disguise, so I try to get the structure right before I get precious about the code.

Lately that means multi-tenant SaaS platforms, AI-powered tools built on real retrieval pipelines (not just a prompt and a prayer), and the occasional deep dive into WebSockets because real-time dashboards are, honestly, just fun to build.
